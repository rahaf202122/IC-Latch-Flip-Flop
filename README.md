# IC Latch and Flip-Flop Homework

## Description

This repository contains a homework assignment for the **Integrated Circuit (IC)** course.

The assignment covers the design and analysis of sequential and basic CMOS circuits, including:

* D-Latch
* Falling Edge Flip-Flop
* Inverter

For the circuits, the homework includes:

* Schematic Design
* Layout
* Simulation
* Discussion and Analysis

## Contents

### 1. D-Latch

* D-Latch Schematic
* D-Latch Layout
* D-Latch Simulation
* Discussion

### 2. Falling Edge Flip-Flop

* Falling Edge Flip-Flop Schematic
* Falling Edge Flip-Flop Layout
* Falling Edge Flip-Flop Simulation
* Discussion

### 3. Inverter

* Inverter Schematic
* Inverter Simulation
